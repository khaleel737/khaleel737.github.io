# Hello World

Welcome to my blog. This is the first post on my terminal portfolio.

## Why a blog?

I wanted a simple place to write about things I'm learning, projects I'm working on, and ideas I'm thinking about. No frameworks, no build tools — just markdown files rendered in the browser.

## How it works

Each post is a `.md` file in the `posts/` directory. A small script on the blog page fetches the markdown and renders it using [marked.js](https://github.com/markedjs/marked). To add a new post, I just:

1. Write a new `.md` file in `posts/`
2. Add an entry to `posts/posts.json`

That's it. Simple and maintainable.
